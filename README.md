# Linear-Regression-Model
# 🏡 House Price Prediction using Linear Regression

This project is a Machine Learning model built in Python that predicts house prices based on features like **Area** and **Location** using the **Linear Regression Algorithm**.

---

# 📌 Project Overview

The goal of this project is to predict the price of a house by training a Linear Regression model on housing data.

The model learns the relationship between:

- Area of the house
- Location of the house

and predicts:

- House Price

---

# 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

---

# 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| Area | Size of the house in square feet |
| Location | City of the house |
| Price | House price in PKR |

---

# 🧠 Machine Learning Workflow

1. Load Dataset
2. Data Preprocessing
3. Label Encoding
4. Train/Test Split
5. Train Linear Regression Model
6. Predict House Prices
7. Evaluate Model Performance

---

# 📈 Linear Regression Formula

The model uses the Linear Regression equation:

y = m₁x₁ + m₂x₂ + c

Where:

- y = Predicted House Price
- x₁ = Area
- x₂ = Location
- m₁, m₂ = Coefficients
- c = Intercept

---

# 📊 Model Performance

- R² Score: Excellent accuracy achieved
- Mean Squared Error: Very low error
